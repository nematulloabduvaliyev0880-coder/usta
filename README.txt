USTAOS — STARTUP MVP
====================

ISHGA TUSHIRISH
1. ZIP faylni kompyuterga yuklab oling va arxivdan chiqaring.
2. UstaOS papkasini Visual Studio Code orqali oching.
3. index.html faylini brauzerda oching.
   Tavsiya: VS Code ichida Live Server kengaytmasidan foydalaning.

FAYLLAR
- index.html : sahifalar va HTML tuzilishi
- style.css  : dizayn va mobil moslashuv
- app.js     : JavaScript funksiyalari va ma'lumotlar

HOZIR ISHLAYDIGAN FUNKSIYALAR
- Boshqaruv paneli va ko‘rsatkichlar
- Buyurtma qo‘shish, tahrirlash, o‘chirish
- Buyurtmalarni qidirish va holat bo‘yicha filtrlash
- Mijoz qo‘shish va o‘chirish
- Xizmatlar qo‘shish va o‘chirish
- Xarajat qo‘shish va o‘chirish
- Daromad/xarajat hisoboti
- CSV hisobot yuklab olish
- Biznes sozlamalari
- localStorage orqali brauzerda saqlash

MUHIM CHEKLOV
Bu hozircha frontend MVP/prototip. Ma'lumotlar faqat shu brauzer va qurilmada saqlanadi.
Haqiqiy SaaS ishga tushirishdan oldin:
- Firebase Authentication yoki boshqa xavfsiz login
- Firestore/ma'lumotlar bazasi
- Har bir biznes uchun alohida ma'lumot ruxsatlari
- Server tomonda validatsiya va xavfsizlik qoidalari
- Zaxira nusxa, maxfiylik siyosati va sinovlar
qo‘shilishi kerak.

Keyingi bosqich: Firebase ulash, login/ro‘yxatdan o‘tish va har bir ustaning alohida kabinetini yaratish.
